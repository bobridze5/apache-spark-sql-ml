# Работа с фреймворком распределённых вычислений Apache Spark

## Задача
Написать 2 программы:

Программа A (работа с компонентом Spark SQL) представляет собой набор запросов к базе данных "brooklyn_sales_map.csv".

Программа B (работа с компонентом SparkMLib) осуществляет построение трёх моделей машинного обучения: логистическая 
регрессия, дерево решений и случайный лес для набора данных. Для каждого алгоритма необходимо получить лучшую модель, 
путём поиска наилучшего набора её параметров.

Для алгоритма логистической регрессии это параметры:
- maxIter = 10 ... 10000
- regParam > 0 (0.1, 0.5, 1, ...)
- elasticNetParam = 0...1

Для дерева решений:
- MaxDepth > 0 (3, 5, 9, 12, ...)

Для случайного леса:
- maxDepth > 0 (3, 5, 9, 12, ...)
- numTree > 0 (5, 11, 25, ...)

Получить значения матриц ошибок и другие параметры

### Конкретная задача
**Программа A:**
- Найти средний год постройки жилья и вывести новую таблицу, содержащую год постройки жилья и отклонение года постройки 
от среднего значения.
- Подсчитать, сколько различных домов приходится на каждую улицу, и вывести результат в отдельную таблицу.
- Отсортировать датасет по возрастанию цены продажи и убыванию индексов одновременно.
- Вывести таблицу с наибольшими ценами продажи и количеством зданий по каждому сочетанию соседства и категории класса 
здания

**Программа B:**
Набор данных: Оценка вероятности пожара по детекторам физических характеристик среды:
https://www.kaggle.com/datasets/deepcontractor/smoke-detection-dataset

Метка класса: Fire Alarm (0 - нет огня, 1 - есть).
